# Product Catalogue

A small React app where I practised global state management with Zustand. It loads products from the Fake Store API, shows a detail page for each one, and lets you add new products or delete them.

Made as a college project in 2024.

## Features
- Product list loaded from an API
- Product detail page
- Create and delete products
- Shared state with a Zustand store

## Built with
React · Zustand · React Router · Axios · [Fake Store API](https://fakestoreapi.com)

## Run it locally
```bash
npm install
npm start
```
